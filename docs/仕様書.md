# お問い合わせフォーム 仕様書

## 概要
Laravelで実装した「お問い合わせフォーム」。エンドユーザーが問い合わせを送信する公開フォームと、管理者が問い合わせを管理する管理ページから構成される。

## 技術仕様
- フレームワーク: Laravel 13 / PHP 8.3
- データベース: SQLite（`database/database.sqlite`）
- コーディング規約: PSR-12準拠（`vendor/bin/pint` で検証）
- 言語設定: `APP_LOCALE=ja`（画面表示・バリデーションメッセージは日本語）

## データベース

### `contacts` テーブル
マイグレーション: `database/migrations/2026_08_23_002606_create_contacts_table.php`

| カラム名 | 型 | 説明 |
|---|---|---|
| id | bigint (PK) | 主キー |
| name | string | お名前 |
| email | string | メールアドレス |
| subject | string | 件名 |
| body | text | 本文 |
| status | string | ステータス（デフォルト値: `新規`） |
| created_at / updated_at | timestamp | 登録・更新日時 |

### モデル: `app/Models/Contact.php`
- `$fillable`: `name`, `email`, `subject`, `body`, `status`
- ステータス定数:
  - `STATUS_NEW`（新規）
  - `STATUS_IN_PROGRESS`（対応中）
  - `STATUS_RESOLVED`（解決済み）
- `Contact::statuses()`: 管理画面のステータス選択肢（`[値 => ラベル]`）を返す静的メソッド

## ルート一覧（`routes/web.php`）

| Verb | Path | Route名 | Controller@method | 説明 |
|---|---|---|---|---|
| GET | `/` | - | `Route::redirect('/', '/contact')` | `/contact` へリダイレクト |
| GET | `/contact` | `contact.create` | `ContactController@create` | 入力フォーム表示 |
| POST | `/contact/confirm` | `contact.confirm` | `ContactController@confirm` | 入力内容を検証し確認画面を表示 |
| POST | `/contact` | `contact.store` | `ContactController@store` | 確認済み内容をDBに保存 |
| GET | `/contact/thanks` | `contact.thanks` | `ContactController@thanks` | 送信完了画面を表示 |
| GET | `/admin/contacts` | `admin.contacts.index` | `Admin\ContactController@index` | 問い合わせ一覧表示 |
| GET | `/admin/contacts/{contact}` | `admin.contacts.show` | `Admin\ContactController@show` | 問い合わせ詳細表示 |
| PATCH | `/admin/contacts/{contact}/status` | `admin.contacts.updateStatus` | `Admin\ContactController@updateStatus` | ステータス更新 |

管理ページ用ルートは `Route::prefix('admin')->name('admin.')` でグループ化されている。**現時点では認証は未実装**（後から `auth` ミドルウェア等を追加しやすい構成にしてある）。

## 画面・機能仕様

### お問い合わせフォーム（エンドユーザー向け）

確認画面を挟む入力フローは**セッションベース**で実装している（hidden項目での値の再送信ではなく、確認画面表示時にバリデーション済みの内容を `session('contact.input')` に保持する方式）。

1. **入力画面**（`GET /contact` → `resources/views/contact/create.blade.php`）
   - 「お名前」「メールアドレス」「件名」「本文」を入力
   - 確認画面から「戻る」で遷移してきた場合は、セッションに保持された入力値を復元して表示
   - バリデーションエラー時は入力画面に戻り、エラー内容を一覧表示
2. **確認画面**（`POST /contact/confirm` → `resources/views/contact/confirm.blade.php`）
   - `ContactController@confirm` が `ContactRequest` でバリデーションを実行
   - 検証済みの入力内容を `session(['contact.input' => $validated])` に保存し、確認画面に表示
   - 「戻る」リンク（入力画面へ）と「送信する」ボタン（送信処理へ）を表示
3. **送信処理**（`POST /contact` → `ContactController@store`）
   - `session('contact.input')` を読み取り、`Contact::create()` でDBに保存（`status` は常に `新規`）
   - セッションから `contact.input` を削除し、完了画面へリダイレクト
   - セッションに入力内容が無い場合（直接POSTされた場合等）は入力画面へエラー付きでリダイレクト
4. **完了画面**（`GET /contact/thanks` → `resources/views/contact/thanks.blade.php`）
   - 「お問い合わせありがとうございました」を表示

#### バリデーションルール（`app/Http/Requests/ContactRequest.php`）

| 項目 | ルール | エラーになる条件 |
|---|---|---|
| お名前 (name) | `required\|string\|max:255` | 未入力、または256文字以上 |
| メールアドレス (email) | `required\|email\|max:255` | 未入力、メール形式が不正、または256文字以上 |
| 件名 (subject) | `required\|string\|max:255` | 未入力、または256文字以上 |
| 本文 (body) | `required\|string\|max:2000` | 未入力、または2001文字以上 |

エラーメッセージは日本語化済み（例: 「お名前を入力してください。」「メールアドレスの形式が正しくありません。」「本文は2000文字以内で入力してください。」）。`body` の上限文字数（2000）は要件に明記が無かったための暫定値。

### 管理ページ（管理者向け）

1. **一覧画面**（`GET /admin/contacts` → `resources/views/admin/contacts/index.blade.php`）
   - `Contact::latest()->paginate(20)` で新着順・20件ずつページネーション表示
   - 表示項目: お名前・メールアドレス・件名・ステータス・受付日時
   - お名前をクリックすると詳細画面へ遷移
2. **詳細画面**（`GET /admin/contacts/{contact}` → `resources/views/admin/contacts/show.blade.php`）
   - ルートモデルバインディングで対象の問い合わせを取得
   - お名前・メールアドレス・件名・本文・受付日時を表示
   - ステータスを `<select>`（新規／対応中／解決済み）で変更可能
3. **ステータス更新**（`PATCH /admin/contacts/{contact}/status` → `Admin\ContactController@updateStatus`）
   - `UpdateContactStatusRequest` で `status` が `新規`/`対応中`/`解決済み` のいずれかであることを検証
   - 更新後、詳細画面へリダイレクトし「ステータスを更新しました。」をフラッシュメッセージ表示

#### バリデーションルール（`app/Http/Requests/UpdateContactStatusRequest.php`）

| 項目 | ルール | エラーになる条件 |
|---|---|---|
| status | `required`, `in:新規,対応中,解決済み` | 未指定、または3種類の値以外 |

## 未実装・今回のスコープ外

- 添付ファイルなど、上記4項目以外の入力欄

```bash
php artisan migrate   # contactsテーブルを作成

```
- `/` にアクセスすると `/contact` にリダイレクトされる
- フォーム入力 → 確認画面 → 送信 → 完了画面の一連の流れを確認
- `/admin/contacts` で一覧、詳細、ステータス変更を確認
- `vendor/bin/pint --test` でコードスタイルを確認
- `php artisan test` でテストを実行
